# 公考资料

一个面向考公人的资料聚合静态站点，汇聚课程目录、笔记资料群与更新日志，一处入口，直达所需。

## 网站简介

「公考资料」定位为考公备考的一站式导航站，站点本身不做内容承载，而是把分布在腾讯文档中的**课程目录**、**笔记资料群入口**和**更新日志**集中到一个页面。访客打开即可看到当天日期、三大核心入口，以及用于长期跟进的公众号与联系方式。

内容覆盖十大方向：公务员、国考省考、教师、事业、文职、三支、社工、英语、财会、司法。

## 主要特性

- **单文件站点**：全站仅一个 `index.html`，纯静态、零外部依赖，二维码以 Base64 内嵌，可直接拖入 Cloudflare Pages 上传部署。
- **清晰导航**：顶部导航左侧为品牌标识，中间为三个跳转链接（新标签页打开），右侧实时显示当天日期。
- **三张主卡片**：课程目录、笔记网盘群、更新日志，鼠标悬停有上浮动效。
- **私域导流**：页尾展示「高照资料」「高照数量」两个公众号二维码大图，并支持一键复制联系 QQ。
- **全端自适应**：手机、平板、PC 自动缩放布局，右下角提供返回顶部悬浮按钮。

## 部署

Cloudflare Pages → 创建项目 → 上传资产 → 将 `index.html` 拖入即可，无需构建步骤。
